# 親御さんへ：ゲームの使い方

## あそびかた

- デスクトップの「ベノムモンスター」か「しんかんせん うんてんし」のアイコンをダブルクリックします
- 最初に「だれが あそぶ？」で、おにいちゃん／おとうとを選びます。データは一人ずつ別々に保存されます
- ゲームパッドは、つないだあとにボタンを1回押すと使えるようになります

## しんかんせん うんてんし の操作

| | かんたん | ふつう・むずかしい |
| --- | --- | --- |
| すすむ | 「すすむ」ボタン（キーボードの ↑） | レバーを上へ（↑） |
| とまる | 「とまる」ボタン（キーボードの ↓） | レバーを下へ（↓） |
| ドア | 自動 | ドアボタン（D） |
| アナウンス | 自動 | アナウンスボタン（A） |
| けいてき | けいてきボタン | けいてきボタン（スペース） |

## 困ったとき（遠隔サポート）

Windows の「クイック アシスト」を使って、こちらから操作します。

1. スタートメニューで「クイック アシスト」と入力して開きます
2. 「サポートを受ける」に、こちらから伝える **6けたのコード** を入力します
3. 「画面の共有を許可しますか？」と出たら「許可」を押します

終わったら、ウィンドウを閉じれば接続が切れます。

## 注意

- ゲームは、電源を入れてサインインしたときに自動で新しくなります（ネットにつながっているときだけ）
- ブラウザの「閲覧データの削除」でサイトデータを消すと、ゲームのセーブも消えます
