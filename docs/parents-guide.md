# 親御さんへ：ゲームの使い方

## あそびかた

- デスクトップの「ベノムモンスター」か「しんかんせん うんてんし」のアイコンをダブルクリックします
- 最初に「だれが あそぶ？」で自分の名前を選びます。はじめての人は「＋ あたらしく はじめる」で名前を入れます。データは名前ごとに別々に保存されます
- ゲームパッドは、つないだあとにボタンを1回押すと使えるようになります

## 遊ぶ時間（どちらも1回15分くらいで終わります）

- **ベノムモンスター**：1回のプレイで、たまご1つを「かんせいたい」まで育てます（約15分）。完成するとその日は「きょうは おしまい」になり、次のたまごは翌日からです。
  - もう1回遊ばせてよい日は、「せってい」→「おうちの かた：きょう もう1ぴき」→「ゆるす」を押し、出てくるかけ算に答えてください。
  - バトルはじゃんけんです（✊グー＝はやいこうげき、✌️チョキ＝どく、🖐️パー＝まもり）。生き物ごとに3つの技を持っていて、選んだ技の手でじゃんけんをします。勝った方が先に攻撃し、負けた方も反撃します。キーボードの 1・2・3 でも選べます。
  - 強い技は使うと1〜2ターン休み（⏳）になります。相手の技の休みも画面に出るので、「いま相手はグーが出せない」と読んで戦えます。
  - トレーニングやバトルのあとに、たまに新しい技をひらめき、入れかえられます。
- **しんかんせん うんてんし**：どのコースも運転は約7〜13分です。速く走っているあいだは自動で「はやおくり」になります。終点に着くと「うんてん おしまい」の画面が出ます。

## しんかんせん うんてんし の操作

本物と同じように、アクセルとブレーキの2本のレバーで運転します（どのモードも同じです）。

| 操作 | キーボード | ゲームパッド |
| --- | --- | --- |
| アクセルを強く／弱く | W／S | 右トリガー（押しこむほど強く） |
| ブレーキを強く／ゆるめる | ↓／↑ | 左トリガー（押しこむほど強く） |
| ドア | D | A ボタン |
| アナウンス | A | X ボタン |
| けいてき | スペース | B ボタン |

かんたんモードでは、ドアとアナウンスは自動です。

## 困ったとき（遠隔サポート）

Windows の「クイック アシスト」を使って、こちらから操作します。

1. スタートメニューで「クイック アシスト」と入力して開きます
2. 「サポートを受ける」に、こちらから伝える **6けたのコード** を入力します
3. 「画面の共有を許可しますか？」と出たら「許可」を押します

終わったら、ウィンドウを閉じれば接続が切れます。

## 注意

- ゲームは、電源を入れてサインインしたときに自動で新しくなります（ネットにつながっているときだけ）
- ブラウザの「閲覧データの削除」でサイトデータを消すと、ゲームのセーブも消えます
